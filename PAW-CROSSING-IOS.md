# Paw Crossing for iOS

Build plan for an iOS-only App Store version of **Paw Crossing**, started from scratch in a new repository.
The game itself already exists as a web game; this repo wraps it as a native iOS app with in-app purchases (RevenueCat) and ads (AdMob).

## Decisions (settled)

| Topic | Decision |
| --- | --- |
| Platform | iOS only (iPhone first, iPad allowed but not optimised) |
| Approach | Capacitor app around the existing three.js game (WKWebView), not a native rewrite |
| Purchases | **One-time purchases only, no subscriptions.** Managed with **RevenueCat** |
| "Paw Club" | Kept as a name, sold as a **one-time lifetime unlock** (see Products) |
| Ads | **Google AdMob**: rewarded and interstitial. No banners |
| App Store category | **Games › Casual**, general audience (not the Kids category), age rating 4+ |
| Repository | New, separate repo. The web version stays on the website, untouched |

## 2. Tech stack

- **Vite** (vanilla JS) to bundle the game. No CDN at runtime: three.js, N8AO, postprocessing and Phosphor become npm dependencies so the app works offline.
- **Capacitor** (current stable) with the iOS platform.
- Plugins:
  - `@revenuecat/purchases-capacitor`: purchases, entitlements, restore
  - `@capacitor-community/admob`: rewarded and interstitial ads, ATT prompt, UMP consent form
  - `@capacitor/preferences`: save data (replaces `localStorage`)
  - `@capacitor/haptics`: vibration feedback
  - `@capacitor/app`: pause on background, resume
  - `@capacitor/status-bar`, `@capacitor/splash-screen`
  - Game Center: no official plugin. Write a small custom Capacitor plugin in Swift (GameKit: authenticate, submit score, report achievement, show leaderboard)
- Xcode (latest), iOS deployment target 16.0+.

Check each plugin's current docs before installing; versions move fast.

## 4. Setup from zero

```bash
npm create vite@latest paw-crossing-ios -- --template vanilla
cd paw-crossing-ios
npm i three postprocessing n8ao @phosphor-icons/web
npm i @capacitor/core @capacitor/ios @capacitor/preferences @capacitor/haptics @capacitor/app @capacitor/status-bar @capacitor/splash-screen
npm i @revenuecat/purchases-capacitor @capacitor-community/admob
npm i -D @capacitor/cli
npx cap init "Paw Crossing" com.emredardagan.pawcrossing --web-dir dist
npx cap add ios
npm run build && npx cap sync ios
npx cap open ios
```

The bundle id `com.emredardagan.pawcrossing` is a suggestion; it must match App Store Connect.

Changes needed when moving the code over:

1. Replace the import map with npm imports (`import * as THREE from 'three'`, `three/examples/jsm/...`).
2. Asset URLs: `toybox.js` builds paths from `import.meta.url`; point them at `/assets/` served from `public/`.
3. Replace `store.get/set` (localStorage) with `platform/save.js` (Preferences). Load everything once at boot into memory, write through on change.
4. Respect safe areas (`env(safe-area-inset-*)` is already used in places; check the HUD under the Dynamic Island).
5. Lock to portrait.
6. Pause the loop and audio on `App` `pause`, resume on `resume`.

## 5. Platform layer

Game code never calls a plugin directly. It only talks to `platform/`. On the web (`npm run dev` in a browser) every function has a stub, so the game stays playable without a device.

```js
// platform/ads.js
export async function initAds()                 // consent (UMP) → ATT → AdMob.initialize
export function canShowInterstitial()           // false if entitlement no_ads, or caps not met
export async function maybeShowInterstitial(reason) // applies frequency rules, preloads the next one
export async function showRewarded(placement)   // resolves true only if the reward was earned
export function rewardedReady()                 // for greying out buttons

// platform/purchases.js
export async function initPurchases()           // Purchases.configure({ apiKey })
export async function getShopPackages()         // from the current Offering
export async function buy(pkg)                  // returns updated entitlements
export async function restore()
export function has(entitlement)                // 'no_ads' | 'paw_club' | 'pack_safari' | 'pack_legendary'
export function onEntitlementsChanged(cb)

// platform/save.js
export async function loadSave()                // { coins, owned, best, missions, mlevel, muted, settings, stats }
export function save(patch)

// platform/haptics.js
export function hop(), coin(), hit(), success()

// platform/gamecenter.js
export async function signIn(), submitBest(score), unlock(achievementId), showLeaderboard()
```

RevenueCat calls behind `purchases.js`: `Purchases.configure`, `getOfferings`, `purchasePackage`, `getCustomerInfo`, `restorePurchases`, and the customer-info update listener.

AdMob calls behind `ads.js`: `initialize`, `requestConsentInfo`/`showConsentForm`, `trackingAuthorizationStatus`/`requestTrackingAuthorization`, `prepareInterstitial`/`showInterstitial`, `prepareRewardVideoAd`/`showRewardVideoAd`, and the rewarded event to confirm the reward.

## 6. Products (RevenueCat + App Store Connect)

All one-time. Create them in App Store Connect, import into RevenueCat, attach to entitlements, and put them in one **default Offering**.

| Product id | Type | Grants (entitlement) | Price (suggested) |
| --- | --- | --- | --- |
| `remove_ads` | Non-consumable | `no_ads` | $2.99 |
| `paw_club` | Non-consumable | `no_ads` + `paw_club` | $6.99 |
| `pack_safari` | Non-consumable | `pack_safari` (lion, tiger, elephant, giraffe) | $1.99 |
| `pack_legendary` | Non-consumable | `pack_legendary` (caterpillar, fish + Golden Dog) | $3.99 |
| `coins_500` | Consumable | 500 coins | $0.99 |
| `coins_1500` | Consumable | 1,500 coins | $2.99 |
| `coins_4000` | Consumable | 4,000 coins | $4.99 |

**Paw Club (lifetime) includes:**

- No interstitial ads (rewarded ads stay optional).
- 2× coins from coins, gems, season bonuses and mission rewards.
- Daily gift ×3.
- An exclusive pet: **Golden Dog** (the dog model with a gold metallic material).
- A small paw badge next to the score.

Rules:

- Entitlements are the only source of truth. On boot and on every customer-info update, read `has('no_ads')` and the others and apply them.
- Pets in packs can still be bought with coins; a pack just unlocks them all at once.
- Consumable coins are granted by the app after a successful purchase. Save immediately, and log the transaction id so a coin pack is never granted twice. (Optionally evaluate RevenueCat's virtual currency feature for server-side coin balances.)
- **Restore purchases** button in Settings (App Review requires it).
- Shop screen is our own UI (matches the game's look), built from the Offering's packages and their localized prices. Never hard-code prices in the UI.

## 7. Ads (AdMob)

**Never during a run.** Ads only appear between runs and in menus.

| Placement | Type | Rule |
| --- | --- | --- |
| Game over: **Continue** | Rewarded | Once per run, only if score ≥ 10. Revives at the last safe tile with a 2 s shield. Not offered for "Too slow" |
| Game over: **Double coins** | Rewarded | Once per run, doubles the coins of that run |
| Shop: **Watch for +15 coins** | Rewarded | Max 5 per day |
| Daily gift: **Double it** | Rewarded | Optional, once per day |
| Mission complete: **2× reward** | Rewarded | Optional, on the game-over screen |
| Game over → next run | Interstitial | Every 3rd finished run, at least 120 s since the last interstitial. Never in the first session or the first 3 runs. Skipped if a rewarded ad was watched on that screen |
| Pets screen → play | Interstitial | Same counter and cooldown as above |

- `no_ads` (Remove Ads or Paw Club) turns off **all interstitials**. Rewarded ads stay, because the player chooses them.
- Frequency numbers (3 runs, 120 s, 5 per day, score ≥ 10) live in one config object. Read overrides from the RevenueCat Offering **metadata** so they can change without an app update.
- Preload the next ad right after showing one. If an ad isn't ready, hide or grey out the rewarded button. Never block the player waiting for an ad.
- During an ad: pause the game loop and mute `Sfx`. Resume after it closes.
- Use Google's **test ad unit IDs** in development and TestFlight builds. Switch to real IDs only for the release build, controlled by a build flag.
  - Test app ID (iOS): `ca-app-pub-3940256099942544~1458002511`
  - Test interstitial: `ca-app-pub-3940256099942544/4411468910`
  - Test rewarded: `ca-app-pub-3940256099942544/1712485313`

## 8. Privacy and compliance

The game looks child-friendly, so be careful even though it is not in the Kids category.

- **Consent order on first launch:**
  1. UMP consent form (EEA/UK users)
  2. ATT prompt, shown after the first run, not on launch, with a friendly pre-prompt screen
  3. `AdMob.initialize`
- `Info.plist`:
  - `GADApplicationIdentifier`
  - `NSUserTrackingUsageDescription` ("Lets us show ads that are more relevant to you. Paw Crossing works the same either way.")
  - `SKAdNetworkItems` (Google's current list)
- `PrivacyInfo.xcprivacy` privacy manifest (check that the AdMob and RevenueCat SDKs ship theirs too).
- AdMob settings:
  - Max ad content rating **G**
  - Block sensitive categories (gambling, dating, alcohol, politics)
  - No child-directed tag, since the app isn't for children (re-check if the audience changes)
- App Store privacy labels: identifiers and usage data used for advertising (AdMob), purchase history (RevenueCat).
- In-app **Settings**: sound, haptics, quality, restore purchases, privacy choices (re-open the UMP form), credits.

## 9. Native polish

- **Game Center:**
  - Leaderboard `best_score`
  - Achievements: each season reached, first stampede survived, 10 slides on ice, a full pet collection, 100 close calls
- **Haptics:** light on hop, soft tick on coin, heavy on death, success pattern on mission complete and purchase.
- **Quality setting (auto by device, adjustable in Settings):**
  - **High:** N8AO on, 2048 shadow map, pixel ratio 2
  - **Low:** N8AO off, 1024 shadow map, pixel ratio 1.5, fewer rain drops and particles
  - Target 60 fps on iPhone 11 and newer
- App icon (pet face on the logo colours), launch screen in the sky blue, portrait lock, no status bar during play.
- Background audio: pause when the app is backgrounded or a call comes in.

- [ ] Every product bought in sandbox with a StoreKit configuration file, then with a sandbox tester on TestFlight

- [ ] Airplane mode: game fully playable, shop shows "offline", rewarded buttons hidden
- [ ] Interstitial caps: 3 runs / 120 s / none after a rewarded ad
- [ ] Continue revive: once per run, safe tile, shield, works on logs, ice and boats
